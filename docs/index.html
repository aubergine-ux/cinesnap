Getting started

The defaults are chosen so that the first recording already looks good. There are three steps.

  1. Record. Pick a screen or window, optionally a microphone and webcam, and press Start recording. The window gets out of the way. On Wayland the system asks which screen or window to share.
  2. Stop. Bring Cinesnap back and press Stop. The last moments, where you were reaching for the stop button, are trimmed for you (you can undo that).
  3. Export. The editor opens with zooms already placed on your clicks and typing. Press Export for an MP4 or a GIF.

ffmpeg

Cinesnap uses ffmpeg for capture and encoding. If it is not installed, the start screen offers to download it into Cinesnap's own data folder; nothing is installed system-wide. To use a specific build, set CINESNAP_FFMPEG=/path/to/ffmpeg.

Editing

A recording is never modified. Zooms, cuts, cursor and framing are settings applied on top of it, so everything can be changed or undone at any time.

Zoom segments

Blocks on the zoom track. Drag to move, drag an edge to resize, double-click empty track to add one, Delete to remove. Each has its own zoom level, ease-in/out time and easing curve, and either follows the cursor or stays on a fixed point.

Auto-zoom

Generates a segment for each click and typing burst. Activity closer together than Merge clicks within shares one zoom that follows the cursor. Regenerating keeps every segment you edited or added by hand.

Cuts and trims

Drag the handles at either end of the cut track to trim. Press S at the start and again at the end of a section to cut it out, or switch on cut mode with C and drag across the timeline.

Cursor

The real cursor is not in the recording; a larger one is drawn from the event log. Adjust its size, how strongly its path is smoothed, click ripples, and whether it hides when idle. The cursor is always exactly on target at the moment of a click.

Frame

Padding, rounded corners and drop shadow, over a solid colour, a gradient, an image, or a blurred wallpaper. Aspect presets: 16:9, 9:16 for shorts, 1:1, 4:3, or the recording's own shape.

Crop

Show only part of the recording: set the left, top, width and height in the Crop section. The full recording stays in the file, so the crop can be changed or removed later. A region chosen before recording is stored the same way.

Webcam

If a webcam was recorded it appears as a circle or rounded square in a corner of your choice, and can be hidden without re-recording.

Wayland, in detail

Wayland does not let applications see the pointer or the keyboard outside their own windows. Cinesnap gets the cursor position from the screen-sharing stream itself, and button presses from the kernel input devices, which are readable by members of the input group:

sudo usermod -aG input $USER   # then log out and back in

Without that, clicks are estimated from where the cursor comes to rest, which works well for deliberate point-and-click demos and less well for fast work. Only the fact that a key or button went down is recorded, never which key. Taps on a touchpad are produced by the compositor and are only seen through estimation.

Playback in the editor uses the system's WebKitGTK and GStreamer; make sure the H.264 decoder is installed (gst-libav or gstreamer1.0-libav).

Command line

Recordings are plain folders (*.cinesnap) in Videos/Cinesnap. They can be rendered without the app, which is useful in scripts and CI.

# render with the settings saved in the project
cinesnap render "My demo.cinesnap" -o demo.mp4

# a README-sized GIF, and a vertical cut for shorts
cinesnap render "My demo.cinesnap" -o demo.gif
cinesnap render "My demo.cinesnap" -o short.mp4 --aspect 9:16 --preset 1080p

# open a recording straight in the editor
cinesnap "My demo.cinesnap"

# record five seconds without opening the window
cinesnap record out.cinesnap --seconds 5

# what this machine supports: capture, cursor, clicks, encoder, devices
cinesnap doctor

On a machine without a desktop, build the same command line on its own with cargo build --release -p cinesnap-core; the binary is called cinesnap-cli and has no GUI dependencies.

The bundle layout and the event log are documented in recording-format.md; the design is in architecture.md.

Troubleshooting

No zooms were generated

No clicks were seen. On Wayland, check the note on the start screen about the input group. You can always add zooms by double-clicking the zoom track.

The cursor is small and jittery

Your compositor's portal does not provide cursor metadata, so the system cursor was recorded into the video and cannot be redrawn. Zooms and framing still work.

Preview is black on Linux

Install the GStreamer H.264 decoder (gst-libav). Start Cinesnap from a terminal to see the reason: a line starting with ui: video error. Exports are unaffected because they do not go through the web view.

Export fails with a hardware encoder

Start Cinesnap with CINESNAP_ENCODER=libx264. For VA-API on a non-default GPU set CINESNAP_VAAPI_DEVICE.

macOS records a black screen

Grant Screen Recording permission to Cinesnap in System Settings → Privacy & Security, then restart the app.

A recorded window moved

On Windows, macOS and X11 a window is recorded as the part of the screen it occupied when recording started. Keep it in place, or record the whole screen and use Crop in the editor.
